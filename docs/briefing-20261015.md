## 이번 정리

현재 실행 환경과 회사 자료는 보존했습니다. `.venv/py311` 중복 환경, `.pytest_cache`, `.ruff_cache`, 소스·테스트의 `__pycache__` 6개, PR 작성 임시문서의 총 10개 항목을 보관 폴더로 이동했습니다. 원래 상대경로 구조를 유지했습니다. 중복 환경의 파일 크기 합은 약 710MB이며 보관 이동이므로 디스크 여유 공간이 늘어난 것은 아닙니다.

일괄 삭제가 자동 안전 검토 정책에 의해 차단되어 영구 삭제 대신 복구 가능한 이동으로 정리했습니다. 다운로드한 회사 원본 자료와 저장소의 `dataset_sample`은 수정·이동하지 않았습니다. 기존 소스와 역사적 검증 문서도 그대로 유지했습니다. 보관한 로컬 생성물은 Git에서 제외하며 이 브리핑 문서만 공유합니다.

## 수정한 기능

1. 기타 인공물 라벨을 해제하면 최종 기타 설명도 비워 검수 화면과 JSON 내보내기를 맞췄습니다.
2. 새 작업은 낮은 신뢰도도 필수 검수합니다. 기존 core 시험용 동작은 경고와 함께 유지하지만 본처리는 기존 작업도 필수 검수합니다. Gate에 사람 검수 범위를 표시합니다.
3. 실제 이미지 크기·모델·detail·프롬프트/스키마·출력량으로 요청별 비용을 예약합니다. 미확인 모델은 명시적 추정치가 필요하며 재시도·미확정 예약·동시 작업 잠금을 포함합니다. 공급자 과금 상한은 아닙니다.

스키마 7은 예약 추정치 변경 이력을 추가합니다. 기존 DB는 자동 백업 후 전환하므로 전환한 DB를 구버전 앱으로 열지 마세요.
