## 회사 학습 작업으로 전달하는 순서

1. 원본을 보관하고 `dataset_sample`의 이미지·JSON을 읽기 가능한 위치에 준비합니다.
2. 로컬 프로젝트에 등록하고 후보·보류·제외 수량을 확인합니다.
3. 시험용 50건으로 파일 접근·AI 설정·검수 저장·별도 내보내기를 확인합니다.
4. 선정한 고유 3,000건을 분석하고 필수 검수를 완료합니다.
5. Final Gate 통과 후 새 폴더로 내보내고 회사 담당자가 파일 형식과 split을 확인합니다.
6. 외부 학습 코드에 정제한 train을 지정하고 val로 설정을 결정합니다. 같은 고정 test에서 기존 모델과 재학습 모델을 평가합니다.

기존 API Key 파일을 자동 검색하거나 자격 증명을 GitHub에 저장하지 않습니다. 외부 모델이 영역 단위 예측을 출력하면 이 앱의 장면 라벨 평가와 대응시키는 절차가 필요합니다. bbox/mask·IoU·학습 실행 기능은 현재 제공하지 않습니다.
