# v0.1.3 품질 검수 및 본작업 준비

## 저장 문제 수정

- 미확정 체크박스를 변화 있음으로 바꾼 경우도 수정 감지 및 자동 임시 저장합니다.
- DRAFT/DEFERRED에는 0/1/null과 미해결 상하위 모순을 보존합니다. DONE과 내보내기는 완전한 유효 라벨만 허용합니다.
- Undo는 미확정·모순 원본까지 초안으로 복원합니다. 팀 보류 ZIP에도 null을 보존합니다.
- JPEG 헤더뿐 아니라 전체 픽셀 디코딩을 검사하여 잘린 파일을 Import에서 차단합니다.

## 새 화면: 데이터 품질 · 준비

1. 데이터 가져오기 및 시험용 분석·비교 후 `품질 목록 새로고침`을 누릅니다.
2. 시험용/본작업 기준을 선택하여 유형별 차단·경고를 확인합니다. 기준 변경 후 새로고침합니다.
3. 문제 목록이나 중복 비교 행을 두 번 클릭하면 해당 검수 항목으로 이동합니다.
4. 포함·제외 탭 또는 중복 행에서 제외 대상을 선택하고 사유를 입력합니다. 원본 삭제가 아니라 해당 준비 작업의 제외 결정입니다. 목록을 새로고침하여 결과를 확인하세요.
5. `준비 가능 여부 확인`으로 미완료 검수·중복을 해결합니다.
6. `새 데이터셋 만들기`를 누르고 원본/프로젝트와 겹치지 않는 부모 폴더를 고릅니다.

생성 폴더는 `prepared-<id>/dataset`과 `preparation-manifest.json`으로 구성됩니다. 새 프로젝트에는 **dataset 하위 폴더**를 가져오세요. manifest가 있는 부모 폴더는 데이터셋이 아닙니다.

복사본은 원본 해시를 재확인하고 최종 JSON을 작성한 뒤 production 규칙으로 재검사합니다. 중복 제외 사유·원본/출력 해시·검수 revision을 manifest 및 DB 이력에 남깁니다. 중도 실패한 staging 폴더는 정리합니다. 전체 `dataset+errors` 후보에서 split마다 유효 샘플 1,000건이 안 되면 `본작업 최소 수량 미달`을 표시하며, 데이터 준비 성공을 3,000건 운영 자격으로 간주하지 않습니다.

일반 Final Gate는 제외 설정으로 우회되지 않습니다. 실제 파일 누락·손상·파싱 오류는 시험용에서도 차단합니다. 이번 제외 기능은 불량 파일을 무시하는 기능이 아닙니다.

## 표본 선정 및 평가

- 본작업은 전체 `dataset+errors`에서 split별 1,000건을 고정하며 출처 + 오류 유형 + 원본 양성 라벨 조합별로 균형 배분합니다.
- 기본 seed는 20260324입니다. 순서에 의존하지 않고 재현되며 선택 ID와 분포를 기록합니다. 기존 작업 계획·선택 샘플은 바꾸지 않습니다.
- 균형 표본은 전체 데이터의 비율을 대표하지 않습니다. 오류 데이터 성능을 전체 데이터 성능으로 보고하지 마세요.
- Golden Set을 고정할 때 목적(평가/학습/탐색)과 split을 명시합니다. 평가용은 val 또는 test만 허용하고 동일 이미지 중복과 다른 split과의 겹침을 거부합니다.
- 기존 Golden Set은 `기존/목적 미지정`으로 표시합니다. 외부 모델 학습 과정의 누수 여부는 이 앱만으로 검증할 수 없습니다.
- 중복 검사는 기존과 같은 파일 해시 방식입니다. 다른 압축·크롭·재인코딩으로 만든 시각적 유사 이미지까지 검출하는 기능은 아닙니다.

## 자동 유지 표본 및 보고서

`통계 · 모델 평가 → 자동 유지 표본 검수`에서 개수와 seed를 선택합니다. 미검수 AUTO_KEEP 중 표본을 고정하고 필수 검수로 전환합니다. 표본 선택과 필수 표시를 한 트랜잭션으로 저장합니다. 표본 검수가 끝나기 전 Final Gate가 차단됩니다. 새로 추가한 표본이 없으면 안내합니다.

`수정률 · 검수 시간`과 `검수 보고서 저장`에서 split/오류 유형별 완료·수정 건수, 원본 수정률, 자동 유지 표본의 수정률, 선정 분포를 확인합니다. 완료 표본 오류율은 완료 표본에만 해당합니다.

시간은 검수 화면에서 입력/저장 간 간격을 최대 30초씩 합산한 **추정 입력 시간**입니다. 오래된 작업에는 시간이 없고 읽기만 한 시간과 전체 작업 소요시간은 같지 않습니다. JSON 보고서에도 이 한계를 표시합니다.
