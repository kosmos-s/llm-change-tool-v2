## 기록

### 2026-10-21 · 1~2단계

- 배포 ZIP과 `.sha256`의 해시가 일치했습니다.
- **에이전트 셸에서 exe를 직접 실행하면 안 됩니다.** Claude Code 셸에서 `Start-Process`로 띄운 배포 exe는
  자체 점검이 종료 코드 1로 끝나고 보고서가 없었습니다(10회 이상 재현). 같은 exe를 WMI로 세션 밖에서 실행하면
  3/3 통과(2~3초)했습니다. 원인은 앱이 아니라 에이전트 실행 환경입니다. 근거는 다음과 같습니다.
  - 같은 태그 소스를 CI와 같은 Python 3.11.9 + PyInstaller 6.22.3로 다시 빌드했습니다. 배포 exe와는
    PE 시각·체크섬 8바이트만 다르고 앱 코드·내장 모듈·DLL 구성이 같았습니다.
  - 그런데도 같은 바이너리가 실행할 때마다 통과·실패가 바뀌었고, 실패한 실행에는 파이썬 오류 기록이 없었습니다.
    외부에서 강제 종료된 것으로 보입니다.
  - 배포 exe를 검사하려면 아래처럼 세션 밖에서 실행하세요.
    ```powershell
    Invoke-CimMethod -ClassName Win32_Process -MethodName Create -Arguments @{ CommandLine = '"<exe>" --self-test --report "<절대경로>.json"'; CurrentDirectory = '<폴더>' }
    ```
    프로세스가 끝날 때까지 기다린 뒤 보고서 JSON을 확인합니다.
- `--gui-smoke`는 셸·WMI 모두 통과했습니다.
- 이 진단에서 `.venv`에 `pyinstaller==6.22.3`을 설치했습니다(`build_windows.bat`과 같은 버전).
  실패한 실행이 남긴 `%TEMP%\llm-change-selftest-*` 20개는 삭제했습니다.

### 2026-10-21 · 3~7단계

- 스크립트: `artifacts/acceptance-0.1.12/run_acceptance.py`(Git 제외).
  - 실행할 때마다 `run-<시각>/` 아래에 새 복사본·`results.json`·`screens/`를 만듭니다.
  - 실제 20건 DB는 SQLite 백업 API로 읽기만 하며, 실행 전후 DB 해시가 같은지 확인합니다.
  - 실행 명령: `$env:QT_QPA_PLATFORM='offscreen'; .venv\Scripts\python.exe artifacts\acceptance-0.1.12\run_acceptance.py`
  - 소스 코드로 실행합니다. 이 브랜치와 v0.1.12의 차이는 오류 안내 문구뿐입니다.
- 최종 실행 `run-20261021-135938`: 38/38 통과.
  - 이름: 없으면 저장 거부, 입력 즉시 기억, 다시 열어도 유지됩니다.
  - 저장·되돌리기: 일반 모드 완료 저장(origin=local)과 되돌리기 후 초안 복귀, 라벨 수정 후 초안 저장을 확인했습니다.
  - 위치: 다시 열면 3번째 항목으로 복원됩니다.
  - 독립 판정:
    - 원본·AI 라벨과 복사 버튼을 숨기고 미확정에서 시작합니다.
    - 미확정 라벨이나 근거 없이 완료하면 저장을 거부합니다.
    - 저장 기록은 origin=blind이고, 되돌리기는 막히며 한국어 안내가 나옵니다.
    - 이력 창은 이전 기록을 숨기고, 모드를 바꿨다 돌아오면 내 판정이 다시 표시됩니다.
  - 마무리 흐름: 복사본 20건을 자동 완료한 뒤 최종 Gate를 통과하고 별도 폴더로 내보냈습니다.
    - 내보낸 JSON은 원본 키 구조를 유지하고, 원본 80개 파일과 실제 DB의 해시는 바뀌지 않았습니다.
  - 재실행: 같은 설정이면 기존 작업을 재사용(설계)합니다.
    - 설정을 바꾸면 새 Mock 결과가 생기고, 이전 결과의 완료 20건은 유지됩니다.
  - 백업·복원: 새 폴더로 복원한 뒤 검수 기록 수(43건)가 일치했습니다.
- 스크립트 수정(앱 버그 아님):
  - 원본 라벨을 그대로 완료 저장하면 지침상 고정값인 `arti_roa_m`에서 거부됩니다. 화면과 같은 정규화를 적용했습니다.
  - 같은 설정 재실행은 기존 작업을 돌려주므로, 설정을 바꿔 새 결과를 만들었습니다.
- **앱 수정 1건(미배포):** 백업이 아니거나 손상된 파일을 복원하면 "작업을 완료하지 못했습니다 … 식별번호"라는
  일반 문구만 나왔습니다. `file is not a database`에 다음 행동을 알려 주는 한국어 안내를 넣고 회귀 테스트를 추가했습니다
  (`tests/test_error_messages.py`).
- 자동 완료 기록의 검수자는 `자동점검(사람 정답 아님)`이고 복사본에만 있습니다. 사람 정답으로 쓰지 마세요.

offscreen 캡처는 한국어 글꼴이 없어 글자가 네모로 나옵니다. 스크립트에서 `C:\Windows\Fonts\malgun.ttf`를 불러와 다시 캡처했습니다.

  - 1480×960 독립 판정 화면은 원본/AI 칸이 「숨김」, 근거 입력란이 비어 있고, 기타 설명도 숨김으로 표시됩니다.
  - 백업·복원 탭은 문구가 맞고 ZIP 교환 카드가 없습니다.
  - Gate 통과 시 "Gate 통과는 전건 사람 검수나 정확도 향상을 뜻하지 않습니다" 안내가 나옵니다.
- **발견 A(미수정, 사용자 확인 필요):** 1366×768에서 검수 이미지가 작게 줄어듭니다.
  - 상단 안내, 요약, 노란 확인 안내, 버튼, 상태, 진행 막대가 세로 공간을 차지하기 때문입니다.
