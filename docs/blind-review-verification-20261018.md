# 독립 판정 후속 검증 · 2026-10-18

사용자의 Claude 계획 참고·코드 수정·테스트 요청에 따라 기존 Claude 커밋
`284541c`와 인계 기록의 독립 판정 동작을 현재 코드와 대조했습니다.
별도 계획 파일은 확인하지 못했으며 이번 변경은 해당 구현의 후속 보완입니다.

## 변경

원래는 검수 출처가 blind이면 검수자 이름과 결과의 최신 여부에 관계없이 판정을
표시했습니다. 다른 사람이 남긴 근거나 오래된 결과가 자신의 독립 판정처럼
나타나는 두 경우를 새 회귀 테스트로 재현했습니다.

이제 현재 이름·blind 출처·현재 비교 결과가 일치하는 경우에만 판정과 근거를
복원합니다. 이력 창에서도 다른 검수자와 이전 결과의 근거를 숨깁니다.
이름 변경 시 해당 이름의 최신 판정 또는 미확정 라벨로 표시를 갱신합니다.
작성 중인 판정을 다른 이름으로 넘기지 않도록 이름 변경을 차단하되, 처음에
이름을 입력하지 않았다면 판정 후 이름 입력과 저장이 가능합니다.
저장 직후에도 검수자와 최신 여부를 화면 상태에 반영합니다.

DB 마이그레이션이나 업무 정책 변경 없이 UI와 회귀 테스트를 보완했습니다.
기존 검수 revision과 원본 파일은 보존했습니다. 사용자 설명서도 갱신했습니다.

## 검증 근거

Windows / Python 3.11.17 / QT_QPA_PLATFORM=offscreen, 합성 자료와 Mock만 사용했습니다.

- 수정 전: 새 회귀 테스트 2건 실패로 다른 검수자·오래된 결과의 근거 노출 재현.
- 1차 관련 검사: 검수·평가 테스트 22개 통과.
- 전체 pytest: **167개 통과**, 701.35초.
- 전체 검사 도중 이름 없이 시작한 입력 흐름을 보완하고 회귀 테스트 1개 추가.
  최종 관련 검사: **23개 통과**, 89.57초. `test_blind_review.py`,
  `test_review_workflow_ui.py`, `test_review_safety.py`, `test_handoff_ui.py`,
  `test_scene_evaluation.py`를 실행했습니다. 마지막 보완 후 전체 모음을 다시 돌린 것은 아닙니다.
- Ruff 검사·포맷 검사·compileall·Git diff 공백 검사 통과.
- 합성 self-test: 6건, pilot, network_calls=0, passed=true.
  Import → Mock → 검수·저장 → 재실행 → 내보내기·백업/복원 흐름을 확인했습니다.
- offscreen GUI 및 worker smoke: passed=true.

실제 회사 자료·작업 DB는 열거나 수정하지 않았습니다. 유료 호출과 실제 모델
추론·재학습은 수행하지 않았으며, 이 테스트 점수는 모델 정확도 향상의 근거가 아닙니다.

## 사용자 PC 확인

실제 앱에서 독립 판정을 켜고 검수자 이름을 바꿨을 때 다른 사람의 근거가
숨겨지는지 확인하세요. 실제 영상 판정·이름 입력·저장·재실행 후 내용과
별도 내보낸 JSON을 사람이 대조해야 실사용 수용 확인이 완료됩니다.

## 회사 미확정 사항

공식 F1/F2·평가 대상과 수행 주체·최종 선정 수량·납품 범위는 기존대로 미확정입니다.
회사 회신 없이 가능한 내부 검수는 계속할 수 있으며, 이번 UI 보완은 회사 기준
확정이나 유료 본처리 승인을 뜻하지 않습니다.
