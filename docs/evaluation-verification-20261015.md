# 평가 기능 추가 검증 · 2026-10-15

기준 배포 v0.1.10 이후 별도 브랜치의 미배포 변경입니다. 내부 기준은 [평가 정책](evaluation-policy.md), 이전 검수·비용 수정은 [인수인계 수정 보고서](handoff-fixes-20261015.md)에 있습니다.

## 실제 추가한 기능

- 대표 지표: 주요 5개 라벨 중 하나라도 1이면 변화 있음으로 보는 영상 쌍 단위 F1. 기존 micro F1·라벨별 점수는 보조로 보존했습니다.
- 같은 고정 정답으로 기존·재학습 모델의 실제 예측을 비교하고 F1 차이·%p 변화·TP/FP/FN/TN을 계산합니다. 정답 변경·서로 다른 세트·누락 예측·개별 예측이 없는 구형 집계는 비교를 차단합니다.
- 사례별 수동 검토 CSV, 독립 수동 집계 대조, 오프라인 CLI를 추가했습니다. 검토표 발급과 사람 검수 완료를 구분합니다.
- v2 예측 양식은 null/미완료로 발급하며 영상 상대경로를 제공합니다. 양식을 그대로 점수화하지 못하도록 하고 기존 v1 실제 예측 입력은 유지했습니다.
- Mock·부분 평가·대표 점수 미정의·구형 집계 한계를 표시했습니다. 영문 사유 선택·제공 자료 전체 후보 사용과 내부 기준을 문서화했습니다.

평가 정보는 기존 model_evaluations JSON payload에 추가합니다. 추가 DB 마이그레이션은 없고 이전 검수·예약 수정의 스키마 7을 유지합니다. 기존 집계로 새 대표 점수를 추정하거나 덮어쓰지 않습니다. 평가 계산과 내보내기는 UI 백그라운드 작업으로 실행합니다.

## 자동 검사

Windows / Python 3.11.17 / QT_QPA_PLATFORM=offscreen:

- 전체 pytest **161개 통과**(452.51초). 이후 최종 양식·표 표시 수정 관련 **15개 재검사 통과**.
- 새 회귀 테스트 7개: 대표/보조 지표 차이, 알려진 혼동행렬·누락·미정의, 동일 정답 제한·정답 변경, 구형 평가 호환, 미완료 양식 차단·v1 입력, UI 구분, CLI·재실행·백업/복원·JSON 내보내기·원본 보존.
- Ruff 검사·포맷, compileall, 자체 self-test(합성 6건 / network_calls=0), GUI·worker smoke 통과. 한국어 합성 UI 캡처를 확인하고 점수 표의 대상 열을 넓혀 대표/보조 구분이 보이도록 했습니다.

합성 정답과 가상 예측으로 계산이 맞는지 확인한 것입니다. 테스트의 점수 변화는 실제 모델 향상 수치가 아닙니다. GitHub의 최신 커밋 검사 상태는 [PR #11](https://github.com/kosmos-s/llm-change-tool-v2/pull/11)을 확인하세요.

## 실제 파일로 확인한 범위

제공 자료의 dataset/errors와 train/val/test에서 총 20건을 별도 복사했습니다. 최초 표본의 split 누출을 확인한 후 선택 영상 내용의 중복을 제외해 새 시험본을 만들었습니다. 최종 표본은 dataset/errors 각각 train 4·val 3·test 3건이고 Import 품질 오류는 0건입니다. 전체 데이터의 중복·지역 누출 검사가 완료됐다는 뜻은 아닙니다.

최종 시험본에서 Import → Mock 20건 완료 → 비교 → DRAFT 20건 저장 → 다시 열기 → 백업/복원을 확인했습니다. 원본 80개 파일과 복사본의 SHA256이 처리 전후 일치했습니다. 프로젝트·해시 기록·검수용 메모 CSV는 로컬 artifacts/local-reference에만 있으며 Git에서 제외됩니다.

실제 영상의 정답을 사람이 확정하지 않았으므로 완료 검수는 **0건**입니다. Export Gate 차단을 확인했으며 실제 자료의 최종 JSON이나 Golden 정답을 만들어 성과로 보고하지 않았습니다. 완료 검수·최종 JSON 내보내기는 합성 테스트에서 확인했습니다. 실제 자료의 전 흐름 수용 검증은 사용자가 영상을 검수하고 내보낸 JSON을 대조해야 마무리됩니다.

## 남은 입력과 확인

- 사용자 PC: 준비한 20건의 T1/T2와 라벨·사유를 직접 검수하고 저장·재실행·최종 JSON을 대조해야 합니다. Portable 실사용과 실제 API의 판정 정확도는 별도 확인 대상입니다.
- 실제 재학습: 제공 자료 폴더에서 학습 코드·가중치를 찾지 못했습니다. 코드·기존 가중치·학습/추론 명령·환경과 실제 예측이 필요합니다. 자동 평가와 수동 검토 절차는 준비했지만 회사 모델을 실제로 재학습하거나 개선량을 측정하지 않았습니다.
- 회사 기준: 공식 F1/F2·양성 정의·목표, 평가 데이터/수행 주체, 최종 3,000건·제출 범위·일정은 별도 확정이 필요합니다. 내부 기준이나 사용자 파일 사용 허용을 회사 공식 확정·유료 본처리 승인으로 기록하지 않습니다.

유료 API 호출, 회사 서버 접속, 원본 자료 수정, main 병합, 새 릴리스는 수행하지 않았습니다.
