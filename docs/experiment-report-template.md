# 내부 실험 보고서 양식

이 문서는 작성 양식입니다. 미측정 항목을 0이나 추정 성과로 채우지 않습니다. 회사 공식 성과 인정과 별도로 내부 실험을 기록합니다.

## 실험 조건

- 기준 버전: independent-v1 / scene-f1-v1 (변경 시 이유 기록)
- 수행일·검수자: 미기입
- 앱 커밋·모델·프롬프트/설정 해시: 미기입
- 데이터 지문·Golden Set ID/지문·선정 seed: 미기입
- 사용 split·수량·제외/보류 수·선정 방식: 미기입
- 사람 정답 양성/음성 수·중복/지역 누출 확인: 미기입
- 내부 목표: 대표 변화 유무 F1 0.85 이상 (목표이며 측정값 아님)

## 결과

| 항목 | 결과 |
| --- | --- |
| 실제 LLM vs 사람 정답의 대표 F1 | 미측정 |
| 보조 주요 5개 라벨 micro F1 | 미측정 |
| TP / FP / FN / TN, Precision / Recall | 미측정 |
| 완료 / 보류 / 수정 건수·원본 대비 수정률 | 미측정 |
| 검수 시간·시간 측정 방법 | 미측정 |
| 실제 API 사용량·기록된 비용·공급자 청구 대조 | 미측정 |
| 회사 모델 기존/재학습 F1 및 변화량 | 미측정 — 실제 학습/추론 코드와 결과 필요 |

대표 수정 사례와 남은 FN/FP·유형 오류를 별도 로컬 자료로 첨부합니다. 회사 영상·샘플 ID·원본 파일명·DB·키가 포함된 보고서는 공개 저장소에 올리지 않습니다. 표본의 점수와 전체 데이터의 성능을 구분합니다.

## 판정과 다음 실험

임시 목표 충족/미달/판정 불가와 근거를 적습니다. 미달이라면 대표 오류와 val에서 바꿀 설정을 기록합니다. test를 보고 설정을 바꿨다면 이후 독립 test로 재사용하지 않습니다. 비교 시 동일한 정답·모델 실행 조건을 확인하고, 사람 검수 수정률이나 Mock 점수를 실제 모델 성능 개선으로 해석하지 않습니다.
