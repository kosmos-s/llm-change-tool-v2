# 0.1.2 실데이터 수용 검증

3,000건 본작업 전, 허용된 실제 이미지·JSON 30~50건과 사용자 Windows PC에서 아래 흐름을 확인합니다. 자동 테스트는 합성 데이터와 가짜 API 응답을 사용하므로 실데이터 수용 검증을 대신하지 않습니다.

## 준비

1. 새 배포본을 별도 폴더에 압축 해제합니다. EXE와 `_internal`을 함께 유지합니다.
2. 실제 데이터 30~50건을 별도 로컬 폴더에 복사합니다. 각 샘플의 JSON과 combined JPG 또는 left/right JPG를 모두 포함하고 `dataset`과 `errors`의 train/val/test 상대경로를 유지합니다. 중복 샘플은 포함하지 않습니다.
3. 건물·도로·자연 변화·변화 없음·애매한 사례가 섞이도록 선택하고 가능하면 세 split을 포함합니다. 이 소규모 표본의 정확도를 전체 데이터 성능으로 해석하지 않습니다.
4. 데이터 폴더 밖에 새 프로젝트를 만듭니다. 기존 프로젝트 업그레이드를 확인할 때는 자동 생성된 전환 전 DB 백업도 보관합니다. 회사 데이터, API Key, 작업 DB를 GitHub에 올리지 않습니다.

## 검증 순서

| 단계 | 실행 | 통과 기준 |
|---|---|---|
| Import | 공통 상위 폴더를 선택 | 준비한 개수와 일치, 품질 오류 0, T1/T2 방향·색상 정상 |
| 오프라인 흐름 | 시험용 + Mock으로 분석·비교 | 인터넷/API Key 없이 끝남, pilot으로 표시 |
| 실 AI 확인 | 시험용 + OpenAI 작업 생성, 로컬에서 키·모델·단가·예산 입력 후 전송/유료 호출 동의 | 성공·실패·비용 표시, AI 응답과 화면 라벨 일치 |
| 중단·이어하기 | 일부 처리 후 일시정지, 현재 요청 종료를 기다린 뒤 재개 | 같은 작업에서 완료 수 유지, 남은 항목만 처리 |
| 예산 변경 | 일시정지 상태에서 선택 작업 예산 변경 | 같은 작업 ID와 완료 수 유지, 새 한도 표시, 미완료만 재개 |
| 취소·복구 | 별도 시험 작업에서 일부 처리 후 취소하고 다시 열기 | 완료 결과 보존, 재개 가능, 실패 항목은 별도 재시도 |
| 이미지 오류 | 별도 시험용 사본에서 다음 이미지 이름을 잠시 바꾼 뒤 이동 | 이전 이미지 제거, 완료·초안 저장 차단. 파일명 복원 후 새로고침하면 정상 |
| 검수 저장 | 원본 유지·AI 적용·직접 수정을 각각 사용 | 선택만으로 완료되지 않음, 최종 저장 후 완료 수 증가 |
| 필터 | 필수 검수 목록에서 여러 건 연속 저장 | 완료 항목 제거, 다음 미완료를 건너뛰지 않음, 전체 수 유지 |
| 근거 | 라벨·한국어 근거 변경 및 영문 입력 | 이전 영문 제거, 새 한·영 근거가 재실행·내보내기 후 유지 |
| 되돌리기 | 같은 항목에 A→B→C 저장 후 연속 되돌리기 | B→A→원본 순서, 이력 유지, 두 상태 반복 없음 |
| 재실행 | 앱을 닫고 프로젝트 다시 열기 | 완료 수·라벨·근거·예산 일치 |
| Export | 필수 검수 완료 후 품질 확인·내보내기 | 품질 통과, JSON/JPG 개수 일치, 원본 불변, 한국어·영문과 최종 라벨 일치 |
| 기업 툴 호환 | 내보낸 소규모 결과를 기존 학습/검수 도구로 열기 | 키·자료형·설명 필드가 정상 인식됨 |

실 AI 단계는 실제 이미지 전송과 비용이 발생합니다. API Key는 앱에만 입력합니다. 영문 근거가 기업 납품에 필수인지 확인하고, 필수이면 품질 화면의 영문 미입력 수를 0으로 맞춥니다. 현재 앱은 변경된 근거를 자동 번역하지 않습니다.

## 기록 및 본작업 전환

앱 버전, Windows 버전·배율, 샘플 수·split별 수, 작업 ID, 모델명, 실제 소요 시간, 내보내기 개수, 실패 단계와 재현 순서를 기록합니다. 오류 화면을 공유할 때 API Key나 회사 원본 이미지가 노출되지 않도록 합니다.

모든 단계가 통과한 뒤 3,000건용 프로젝트와 production 계획으로 진행합니다. 현재 production은 각 errors split에서 경로순 앞 1,000건을 고정하므로 선정 분포가 의도에 맞는지 먼저 확인합니다. 평가에는 학습용과 분리된 정답 데이터를 사용하고, 과제 문서 사이의 F1/F2 목표 차이를 담당자와 확정합니다.
